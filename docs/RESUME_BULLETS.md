# RoboMotion AI — resume bullets

**RoboMotion AI — Gesture-Controlled Robotic Arm Digital Twin**  
*React, TypeScript, Three.js, React Three Fiber, MediaPipe, Robotics Kinematics*

- Built a browser-based 3D robotic-arm simulator with six manually controlled channels, motion constraints, four pose presets, and forward/inverse kinematics for reachable end-effector targets.
- Integrated opt-in webcam hand-landmark tracking and bounded virtual gesture control with explicit arming, manual override, tracking-loss disarming and an emergency-stop latch.
- Implemented simulated object grasping/docking and a diagnostics dashboard with session-local event logs, safety counters, guided demonstrations and CSV/JSON exports.
